# HORIZON — Brand Architecture

## Parent brand: HORIZON

**Role:** the master brand.

Horizon represents the complete vision: intelligent environments, future living, physical AI, infrastructure, research, development, and long-term urban systems.

Public descriptor:

> **Intelligent spaces. Brighter lives.**

The parent brand should be the dominant identity across the website.

The sub-brands should appear as a future ecosystem, not as competing brands.

## Horizon Cities

### Purpose

Use **Horizon Cities**, not Horizon City, for the business/division.

"Horizon City" can later be used for the name of one specific development if appropriate.

# How the ecosystem fits together

A useful conceptual diagram:

```text
                           HORIZON
                              |
        -------------------------------------------------
        |              |             |          |       |
     LIVING         SYSTEMS         LABS    COMMUNITIES CITIES
        |              |             |          |       |
   Human experience  Intelligence   Research   Neighbourhood  Urban scale
```

A better conceptual relationship is:

```text
HORIZON LABS
   ↓ research

HORIZON SYSTEMS
   ↓ intelligence + infrastructure

HORIZON LIVING
   ↓ building-scale experience

HORIZON COMMUNITIES
   ↓ neighbourhood-scale integration

HORIZON CITIES
   ↓ city-scale integration
```

This should not imply rigid corporate reporting lines. It is a storytelling model for the website.

# Brand hierarchy rule

On every sub-brand:

1. **HORIZON** remains visually dominant.
2. The sub-brand is secondary.
3. The design language remains consistent.
4. Avoid giving each division completely different colours or visual identities.
5. Use iconography and subtle accent differences rather than turning them into unrelated brands.

# Naming note

If a legal entity or domain eventually needs an extended name, something such as **Horizon Works** may be considered separately. It does not need to become another public-facing division.

Do not introduce more sub-brands until a real business need exists.
